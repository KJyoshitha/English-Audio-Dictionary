# Digital English Dictionary

A desktop-based **Digital English Dictionary** built with **Python** and **CustomTkinter**. The application allows users to search for English words, view their meanings, synonyms, antonyms, and listen to pronunciations and definitions using text-to-speech.

## ✨ Features

- Search for English words
- Display word meanings, synonyms, and antonyms
- Suggest correct spellings for misspelled words
- Text-to-speech
- Modern GUI built with CustomTkinter

## 🛠️ Technologies Used

- Python 3
- CustomTkinter
- Tkinter
- NLTK (WordNet)
- pyttsx3
- CTkMessagebox
- JSON

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/KJyoshitha/English-Audio-Dictionary.git
cd English-Audio-Dictionary
```

### 2. Install dependencies

```bash
pip install customtkinter nltk pyttsx3 CTkMessagebox
```


## 🎯 How It Works

1. Enter an English word in the search box.
2. Click **Search** or press **Enter**.
3. The application displays:
   - Meaning
   - Synonyms
   - Antonyms
4. Use the **Audio** buttons to hear the pronunciation or meaning.
